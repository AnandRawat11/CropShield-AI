OVERVIEW — WHAT WE ARE DEPLOYING

Your project has 3 separate services that need to be deployed individually:

  1. AI API (Python FastAPI)     → Render         (ai-api/ folder)
  2. Backend (Node.js Express)   → Render         (server/ folder)
  3. Frontend (React + Vite)     → Vercel         (client/ folder)
  DB: MongoDB                    → MongoDB Atlas  (cloud database, free)

Deploy in this ORDER:
  Step 1: MongoDB Atlas  (database — everything depends on it)
  Step 2: AI API on Render
  Step 3: Backend on Render
  Step 4: Frontend on Vercel

You must finish each step before the next one, because each service needs
the URL of the previous service to configure its environment variables.

    mongodb+srv://cropshield_user:YourPassword@cropshield.xxxxx.mongodb.net/cropshield?retryWrites=true&w=majority

Your server/package.json currently uses nodemon for the start script:
   "start": "nodemon server.js"

Nodemon is only for development. In production, use node directly.
Render looks for "start" script to run your app.

EDIT server/package.json — change the scripts section to:
   "scripts": {
     "start": "node server.js",
     "dev": "nodemon server.js",
     "test": "echo \"Error: no test specified\" && exit 1"
   }

Then commit and push:
   git add server/package.json
   git commit -m "Fix production start script for backend"
   git push

STEP 6: CONFIGURE FRONTEND TO USE PRODUCTION URLS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Before deploying the frontend, you must tell it where your backend lives.
Right now your frontend probably has localhost URLs hardcoded.

CREATE client/.env.production file:
   VITE_BACKEND_URL=https://cropshield-backend.onrender.com
   VITE_AI_API_URL=https://cropshield-ai-api.onrender.com

Also create client/.env.development (for local use):
   VITE_BACKEND_URL=http://localhost:5001
   VITE_AI_API_URL=http://localhost:8000

HOW TO USE THESE VARIABLES IN YOUR REACT CODE:
In any file where you currently have hardcoded localhost URLs like:
   "http://localhost:5001"  or  "http://localhost:8000"

Replace them with:
   import.meta.env.VITE_BACKEND_URL
   import.meta.env.VITE_AI_API_URL

Example — if you have:
   const response = await axios.post("http://localhost:5001/api/disease/predict", ...)

Change to:
   const response = await axios.post(`${import.meta.env.VITE_BACKEND_URL}/api/disease/predict`, ...)

After making these changes, commit and push.

NOTE: The .env.production file should NOT be in .gitignore because Vercel
needs to read it during the build. However, since it only has URLs (no secrets),
it is safe to commit it.

STEP 8: FIX CORS IN YOUR BACKEND
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

After deploying, your frontend (on vercel.app) will try to talk to your
backend (on render.com). Browsers block this by default unless CORS is set up.

Your server.js currently has:  app.use(cors())
This allows ALL origins — which works but is not ideal for production.

To make CORS work properly and securely, update server/server.js:

   Replace:
     app.use(cors());

   With:
     app.use(cors({
       origin: [
         "https://cropshield-ai.vercel.app",
         "http://localhost:5173"  // keep for local dev
       ],
       credentials: true
     }));

   (Replace the vercel URL with your actual Vercel domain from Step 7)

After making this change, commit and push. Render will automatically redeploy.

FIX: Go to Render → cropshield-backend → Logs → Find the error
Most likely cause: MONGO_URI is wrong or environment variable is missing

PROBLEM: AI prediction doesn't work / timeout
FIX: Render free tier "spins down" after 15 minutes of inactivity.
First request after spin-down takes 30-60 seconds.
This is normal on the free tier.
Solution: Keep the service awake using a free tool like UptimeRobot
(https://uptimerobot.com) — set a monitor to ping your AI API URL every 5 min.

PROBLEM: "CORS error" in browser console
FIX: Make sure Step 8 is done and your Vercel URL is in the CORS allowed list.

PROBLEM: Model file not found / AI API crashes
FIX: Make sure ai-api/model/crop_disease_model_fixed.h5 is on GitHub.
Check file size. If > 100MB, use Git LFS (instructions in Step 3).

PROBLEM: MongoDB connection refused
FIX: Make sure Network Access in MongoDB Atlas allows 0.0.0.0/0

PROBLEM: "Cannot find module" on Render
FIX: Make sure you committed package.json changes and Render ran "npm install"
Try: Render → Your service → Manual Deploy → Deploy latest commit

PROBLEM: Vite env variables not working (undefined)
FIX: Make sure ALL environment variables in Vite start with "VITE_"
Other prefixes (like REACT_APP_) do NOT work in Vite.
